# YallDrive Features

## Authentication
*   **Sign Up/Login**: Email & Password authentication via Firebase Auth.
*   **Role Selection**: Users choose between 'Car Owner' or 'Customer'.

## For Car Owners
1.  **Dashboard**: View statistics (Number of registered cars, Feedbacks).
2.  **Add Car**: Upload car details with photos.
3.  **Manage Bookings**: Accept or Reject booking requests from customers.
4.  **Push Notifications**: Receive alerts when a new booking is requested.
5.  **Revenue Tracking**: View earnings.

## For Customers
1.  **Browse Cars**: View list of available cars with search by location.
2.  **Car Details**: View specs, rental price, average rating, and owner info.
3.  **Book Car**: Select date range and send request.
4.  **Reviews**:
    *   Read reviews from other users.
    *   Add a review (Rating 1-5 + Comment) after renting.
    *   Edit/Delete?? own reviews.
5.  **Favorites**:
    *   Heart icon on Car Details.
    *   "My Favorites" page to view saved cars.
6.  **Payments**:
    *   Integration for credit card payments.
    *   View payment history.
7.  **Support**:
    *   AI Chat Support (Customer Help) integrated via Groq/Llama API.
    *   Contact options (Phone, Email, Live Chat).
